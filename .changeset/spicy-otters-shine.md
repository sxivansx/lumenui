Initial release. 16 accessible, themeable React components built on Radix UI and Tailwind CSS v4: Button, Badge, Card, Input, Textarea, Label, Checkbox, Switch, Select, Dialog, Dropdown Menu, Tooltip, Popover, Tabs, Avatar, and Separator. Ships ESM with preserved `"use client"` boundaries, a precompiled `@shivansh.life/lumenui/styles.css`, and a raw token layer at `@shivansh.life/lumenui/theme.css`.
